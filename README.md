# Jay Jalu — Personal Portfolio

A responsive, motion-rich portfolio built with React, TypeScript, Vite, Tailwind CSS v4 and Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository in Vercel. Select the Vite framework preset, build command `npm run build`, and output directory `dist`.

## Before publishing

- Replace `your-email@example.com` in `src/App.tsx` with your professional email.
- Add your resume PDF under `public/` and link it if you want a resume download CTA.
- Verify project descriptions, employment dates and disclosure permissions.
- Project visuals are conceptual illustrations, not production screenshots.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Motion for React
- Lucide React
